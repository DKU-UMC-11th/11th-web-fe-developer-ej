# Week 2 · UMCine

React + TypeScript movie list exercise.

## Run locally

```bash
pnpm install
pnpm dev
```

For a production build, run `pnpm build`.

## Movie assets

Place the provided poster files in `public/images/movies/` using the filenames referenced by `src/data/movies.ts`. The bookmark icons are in `public/icons/`.

Until the poster files are added, cards show a colored title fallback.
